RxJava to Kotlin Coroutines Migration - COMPLETE

Core Changes:
- Migrated all core repositories (SessionRepo, ChannelRepo, PinnedTileRepo, FxaRepo, FrameworkRepo) from RxJava Observable/Subject to Kotlin StateFlow/SharedFlow
- Updated ViewModels (ToolbarViewModel, NavigationOverlayViewModel, WebRenderViewModel, InactiveHintViewModel, HintViewModel) to use Flow/StateFlow
- Converted Application class (FirefoxApplication), MainActivity, and fragment lifecycle components to coroutine-based collection
